# Security policy

Please do not disclose security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting for this repository when it is available.
Otherwise, contact the repository owner privately through their GitHub profile and include:

- the affected route or component;
- the security impact;
- minimal reproduction steps;
- any suggested mitigation.

Do not include real credentials, access tokens, or learner data in a report. Reports will
be acknowledged and assessed as quickly as practical; remediation timelines depend on
severity and deployment risk.
